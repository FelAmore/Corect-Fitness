# Corect Fitness

An AI-powered fitness posture assessment web app that uses real-time pose 
detection to analyse exercise form through your camera.

## Features
- Real-time body pose detection using MediaPipe
- Skeleton overlay visualisation via webcam
- Exercise form assessment (squat, and more)
- React frontend deployed on Vercel

## Tech Stack
- **Frontend:** React, Vite
- **Backend:** Python, FastAPI
- **ML/AI:** MediaPipe, Jupyter Notebook
